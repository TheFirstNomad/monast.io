# Monast

**A global marketplace built on Arc, settled in USDC.**

Monast is the everything-marketplace powered by Arc network, a single hub where
anyone, anywhere, can buy or sell anything using USDC. From token swaps to
physical goods to services, Monast provides one settlement rail and one
trust layer for global commerce.

## Vision

Most marketplaces are siloed by geography, currency, or asset type. Monast
removes those walls:

- **One currency** = USDC as the universal unit of exchange, no FX friction.
- **One chain** = built natively on Arc for fast, low-cost settlement.
- **One marketplace** swaps, goods, and services under a single protocol
  and UI, instead of separate platforms for each.

## What you can do on Monast now

- **Sell goods** list physical products, get paid in USDC, ship anywhere.
- **Offer services**  freelancers and service providers can list, get hired,
  and get paid in USDC without banking rails or cross-border fees.
